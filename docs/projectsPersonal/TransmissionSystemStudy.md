The problem addressed in this project consists of an existing transmission system that contains transmission lines which run through both urban and rural service territory. The existing load at the various buses and the parameters of the existing transmission lines in the system are specified. The existing transmission system consists of 15 buses including 3 generators and a mix of urban and rural load buses which are all interconnected by transmission lines at various voltage levels. The problem posed is to design the transmission system to serve a new load and to determine if the existing transmission system needs to be upgraded to handle a percentage increase in the existing load. To meet this objective, the following studies are carried out for the base case system and for the modified system with the new loads:

1. Power flow analysis
    1. Verify all voltages are in the satisfactory range, with no overloaded lines or transformers.
    2. Determine the total load in the system, the losses, and the total generation.
2. Contingency analysis
    1. Analyze the performance of the system and its ability to perform within specified guidelines following disturbances.
    2. Consider the failure of each transmission line, transformer, and generator under three different cases where each generator is scheduled at its maximum generation.
3. Fault analysis
    1. Determine the fault currents at each bus in the system.
4. Stability analysis
    1. Conduct a transient stability study on the system.

All computations are performed using PSS E v36.
